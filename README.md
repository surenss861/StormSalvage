# Storm Salvage

A multiplayer Roblox game: storms hit a small town, players grab salvage, survive the weather, sell at the
Scrapyard, and buy upgrades. The whole map is generated by code at server start, so the repo is the game.

## Run it

```sh
rokit install                                  # installs rojo, stylua, selene (see rokit.toml)
rojo build default.project.json -o StormSalvage.rbxl
open StormSalvage.rbxl                         # opens in Roblox Studio, then press Play
```

To edit live, run `rojo serve` and connect with the Rojo Studio plugin.

Progress only saves in a **published** place with *Game Settings → Security → Enable Studio Access to API
Services* turned on. Otherwise the game runs with a temporary profile and tells the player.

## The loop

1. Spawn on the Scrapyard plateau (safe zone).
2. Go down into town and grab salvage. Higher-rarity items glow and sparkle.
3. Every ~2.5 minutes a storm hits: **Wind** (flying debris), **Flood** (rising water), or **Lightning**
   (strikes you can see coming). Roofs protect you from wind and lightning. Climb the yellow trusses to
   escape floods.
4. Legendary **Storm Cores** spawn mid-storm. Players still in town when the storm ends get a bonus.
5. Sell at **SELL HERE**, then buy Backpack, Boots, and Armor upgrades at the Gear Shop.
6. If you die, your bag drops where you fell, and anyone can grab it.

## Layout

| Path | What it does |
| --- | --- |
| `src/shared/Config.luau` | All balance: loot values, zone pools, storm timings, upgrade costs, product IDs |
| `src/server/MapBuilder.luau` | Builds the town, buildings, plateau, and props |
| `src/server/StormService.luau` | Weather cycle and the three storm types |
| `src/server/LootService.luau` | Loot spawning, pickups, Storm Cores, death drops |
| `src/server/PlayerService.luau` | Session state, selling, upgrades, damage/armor, autosave |
| `src/server/DataService.luau` | DataStore persistence with a session lock |
| `src/server/MonetizationService.luau` | Game passes and idempotent developer-product receipts |
| `src/client/Main.client.luau` | HUD, shop, tutorial hint, lightning warnings, rain, wind push |
